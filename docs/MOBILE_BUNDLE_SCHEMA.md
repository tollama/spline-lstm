# Mobile Bundle Schema

Schema for smartphone app-side model bundle manifests generated by [scripts/make_mobile_bundle_manifest.py](/Users/yongchoelchoi/Documents/TollamaAI-Github/spline-lstm/scripts/make_mobile_bundle_manifest.py).

Reference examples:

- [mobile_bundle_android_tflite.json](/Users/yongchoelchoi/Documents/TollamaAI-Github/spline-lstm/examples/mobile_bundle_android_tflite.json)
- [mobile_bundle_ios_onnx.json](/Users/yongchoelchoi/Documents/TollamaAI-Github/spline-lstm/examples/mobile_bundle_ios_onnx.json)

## Purpose

The mobile bundle manifest is the contract between exported model artifacts and the native Android/iOS app layer that ships or downloads them.

It answers:

- which runtime the app should load
- which file path inside the app bundle or asset pack should be used
- which app versions are allowed to consume the model
- which exported artifact the bundle came from

## Schema

```json
{
  "schema_version": "mobile_bundle.v1",
  "platform": "android|ios",
  "app": {
    "bundle_id": "ai.tollama.splineforecast",
    "min_version": "1.12.0",
    "build_number": "12034"
  },
  "model": {
    "model_id": "spline-edge-forecast",
    "run_id": "edge-demo-001",
    "semantic_version": "1.2.3",
    "runtime_stack": "tflite|onnx|keras",
    "fallback_chain": ["tflite", "keras"],
    "quantization": "fp16",
    "relative_path": "assets/models/model.tflite",
    "source_export_path": "artifacts/exports/edge-demo-001/tflite/model.tflite",
    "sha256": "<sha256>",
    "size_bytes": 4404019
  },
  "export_artifacts": {
    "export_manifest_path": "artifacts/exports/edge-demo-001/manifest.json",
    "ota_manifest_path": "artifacts/exports/edge-demo-001/ota_manifest.json",
    "edge_eval_path": "artifacts/exports/edge-demo-001/edge_eval.npz"
  },
  "input_specs": [],
  "platform_config": {}
}
```

## Platform-specific `platform_config`

### Android

```json
{
  "asset_pack": "forecast_models",
  "abi_filters": ["arm64-v8a"],
  "runtime_library": "org.tensorflow:tensorflow-lite",
  "min_sdk": 26
}
```

### iOS

```json
{
  "bundle_resource_subdir": "BundleModels",
  "runtime_library": "onnxruntime-mobile",
  "minimum_ios_version": "16.0"
}
```

## Generator usage

```bash
python3 scripts/make_mobile_bundle_manifest.py \
  --platform android \
  --export-manifest artifacts/exports/<run_id>/manifest.json \
  --output /tmp/android_bundle.json \
  --bundle-id ai.tollama.splineforecast \
  --build-number 12034
```

```bash
python3 scripts/make_mobile_bundle_manifest.py \
  --platform ios \
  --export-manifest artifacts/exports/<run_id>/manifest.json \
  --output /tmp/ios_bundle.json \
  --bundle-id ai.tollama.splineforecast \
  --build-number 12034
```

Default runtime selection:

- Android prefers `tflite -> onnx -> keras`
- iOS prefers `onnx -> tflite -> keras`

Override with `--runtime-stack` if the app has an explicit runtime policy.
